# Learn Pace · V0.2 原型与学习闭环复评

基线：2026-11-24《Learn Pace PRD V0.1》及 F01–F12 原图。补充交付为 12 组静态原型、41 个页面/弹层状态。原型数不是 App 路由数；建议维持 P00–P07（7 主页面+1 场景选择）、4 个一级 Tab（首页、问答、路径、我的）。本稿沿用本地优先、LF01/LF02、Android 优先验证的边界；不代表实现完成、模型实测或用户真实学习成绩。

## 1. 原型对应关系

| 组 | 页面/状态 | PRD 需求/验收 | 主要变化 |
|---|---|---|---|
| D01（3） | P02 新建、解释、历史 | LF01-01/02/03、AC-01 | 自由问答入口、可选验证和会话恢复 |
| D02（4） | 选文、Little Tutor、理解反馈、转目标 | LF01-04/05/06、AC-02/03 | 关联子会话、来源保留、反馈不自动计入掌握 |
| D03（3） | P06 Outline 草稿、预览、确认 | LF02-01/02、AC-03/07 | 先修及目标验收标准、Revision、确认后进入 Study |
| D04（3） | 诊断、诊断反馈、费曼检查 | LF02-03/04/06、AC-04 | 诊断不是虚拟练习；概念评估提交原文 |
| D05（4） | 定性部分正确、补救教学、独立复测、达标反馈 | LF02-04/05/06、AC-04 | 使用新情境，教学和验证分离；9/20→10/20 |
| D05Q（3） | 定量未达标、达标、异议 | LF02-06/07、AC-04/05 | 2 次正确上限80%；3 次独立正确达100%；默认门槛90%；作废可重算 |
| D06（4） | 复习队列、独立检索、答后反馈、复习结算 | LF02-08/09、AC-06 | 替代 F12 先展示答案；下一日期、失败回 Study；11/20→10/20 |
| D07（4） | 待答、待评分、问答中断、路径完成 | LF01-07、LF02-10、NFR-04、AC-05/08 | 恢复同一交互，不重复计分；完成仍保留复习 |
| D08（4） | 我的、模型配置与测试、数据管理、恢复预览 | NFR-01/06/07、AC-07/08 | 外部模型、SecureStore、备份恢复、场景切换 |
| D09（3） | P01/P03/P05 同一 Revision 的页面快照 | AC-07 | 统一10/20=50%；4/5、4/8、2/7；实际状态和数量单位 |
| D10（3） | P00 场景选择、P04 目标及资料两步 | LF02-01、AC-03 | 不强制选择；区分导师风格与模型；无课包不虚构资产 |
| D11（3） | 证据详情、提示/跳过/异议、LF02→局部辅导 | LF01-04/05、LF02-05/07、AC-02/05/06 | 能力证据可追溯、区分辅助与独立、保留待答题 |

所有统计均为同一教学示例在不同时间点的快照（D03 初始创建，D04–D06 后续学习，D07-D 更晚的完成状态）。复习日期为演示；实际由 Scheduler 产生。D05Q 的100%为单知识点定量评分，不等于路径进度。原始 F01–F12 如与补充稿冲突，以 V0.2 的交互与数据约束为拟议修订基线。D06 替换 F12；D09/D10 修正 F01–F05、F07–F10 相关布局和数值；F06/F11 讲解页面保留为视觉参考，需去除错误或不匹配题目及未实现功能入口。

## 2. 最终学习闭环复评

| 闭环 | 当前原型覆盖 | 尚未验证 |
|---|---|---|
| LF01 会话 | D01、D02、D07-C：新建、解释、追问、历史、局部辅导、可选理解反馈、恢复 | 流式停止、授权工具、引用权限、重试副作用与真实模型接口 |
| LF01↔LF02 | D02-C、D10、D03、D11-C：转目标及关联局部辅导 | 来源版本、路径/知识点映射、提示暴露、跨流程证据准入 |
| LF02 规划教学 | D03–D05Q：目标、大纲、诊断/教学、定性及定量评估、补救、进阶 | DAG 校验、各知识类型评分合同、修订冲突、目标延期/阻塞 |
| LF02 长期保持 | D06、D07-D、D09：到期、独立检索、评估、复习计划、补救及完成后继续复习 | 真实调度算法、到期/未到期、自报掌握、错题回退、无任务状态、时间变化 |
| 数据恢复 | D07、D08、D09、D11-A：原题/作答恢复、状态一致、证据、备份 | SQLite 事务、幂等、崩溃注入、版本冲突、跨数据库恢复、备份完整性 |

**判定：主路径与关键分支已有原型表达，达到可用于技术 PoC 和需求评审的程度；尚不能判定工程闭环、实际学习效果或全部边界状态通过。** 不需新增独立一级页面；缺口主要是状态、可点击原型、业务契约及可执行验收。
