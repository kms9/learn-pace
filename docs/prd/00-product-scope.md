## 1. 产品目标与范围

### 1.1 目标用户与任务

| 用户 | 核心任务 | 产品价值 |
| --- | --- | --- |
| 中小学学习者 | 自主理解概念、掌握学科知识、复习薄弱点 | 分步辅导、可验证的进度 |
| 成人、自学与考证学习者 | 围绕主题、考试或技能建立学习计划 | 自主定义目标，持续掌握与复习 |
| 自由探索者 | 随时追问、理解与扩展知识 | 无须先创建课程即可学习 |

### 1.2 首期范围

- P0：单设备个人使用、模型配置、LF01 多轮问答与小老师、LF02 精通之路（编辑大纲 / 学习 / 复习会话模式）、评估与证据、自报掌握、复习调度、进度与会话恢复、本地备份。
- P0 不设学习场景选择（2026-11-25 移除原 P00），与 DeepTutor 一致只提供自定义精通目标；无课程资产时不展示虚构的预置课库。学段、学科等课程属性留给 P1 课程包。
- P0 不包含 DeepTutor 的其他学习形态与扩展能力：书籍、沉浸阅读、练习题库、知识库/RAG、Partners、Agents、笔记本、日历等。
- P1：按学段/学科/年级或考试类型提供可选课程包（含来源及版本），扩展学习资料解析、可替换 RAG 服务、更多模型与 iOS 适配验证。
- P2：课程和小游戏的分享/导入与市场、互动教学资源、跨设备同步等。未进入 P0，不将原型中这些能力的占位图标作为已承诺功能。
