Learn Pace 的首期体验以 DeepTutor `1284116` 为蓝本：打开应用即是 DeepTutor 的手机版。问答（含小老师侧聊）与精通之路（编辑大纲 / 学习 / 复习三种会话模式、导师驱动、引擎守门）尽可能复刻 DeepTutor 的功能逻辑、交互、术语与视觉；差异只来自本地优先、DeepSeek Flash、Android 与 P0 范围等工程约束。详见[DeepTutor 手机版复刻方案](../evaluation/deeptutor-mobile-parity-plan-v0.3.md)。

| 主题 | V0.4 决策 | 边界说明 |
| --- | --- | --- |

## 1. 产品目标与范围

### 1.1 目标用户与任务

| 用户 | 核心任务 | 产品价值 |
| --- | --- | --- |
| 中小学学习者 | 自主理解概念、掌握学科知识、复习薄弱点 | 分步辅导、可验证的进度 |
| 成人、自学与考证学习者 | 围绕主题、考试或技能建立学习计划 | 自主定义目标，持续掌握与复习 |
| 自由探索者 | 随时追问、理解与扩展知识 | 无须先创建课程即可学习 |

### 1.2 首期范围

- P0：单设备个人使用、模型配置、LF01 多轮问答与小老师、LF02 精通之路（编辑大纲 / 学习 / 复习会话模式）、评估与证据、自报掌握、复习调度、进度与会话恢复、本地备份。
- P0 不设学习场景选择（2026-11-25 移除原 P00），与 DeepTutor 一致只提供自定义精通目标；无课程资产时不展示虚构的预置课库。学段、学科等课程属性留给 P1 课程包。
- P0 不包含 DeepTutor 的其他学习形态与扩展能力：书籍、沉浸阅读、练习题库、知识库/RAG、Partners、Agents、笔记本、日历等。
- P1：按学段/学科/年级或考试类型提供可选课程包（含来源及版本），扩展学习资料解析、可替换 RAG 服务、更多模型与 iOS 适配验证。
- P2：课程和小游戏的分享/导入与市场、互动教学资源、跨设备同步等。未进入 P0，不将原型中这些能力的占位图标作为已承诺功能。

### 1.3 V0.4 M2-C 可选扩展（P1，待评审）

新增移动端 Skill 管理、基于授权工具的 Skill 使用、通用外部 KnowledgeProvider 与首个 ima 只读知识库；作为独立可选提案推进，不替换上方已纳入的 Change 10–12。现有 P0 不依赖 Skill/知识库，范围、导航及掌握规则不变。详细需求、场景、边界和验收见 [PRD 10](10-mobile-skills-and-ima-knowledge.md)；不承诺市场、任意脚本执行、远程 MCP、完整本地 RAG 或 ima 写入。
