# 04 · LF02 精通之路

> V0.3 拟议基线（2026-11-25）：流程参照 DeepTutor `1284116` 的精通之路（`deeptutor/capabilities/mastery/`、`deeptutor/learning/`、`web/components/space/learning/`）。导师在会话中调用工具推进，引擎判定掌握。参见[复刻方案 §3.5–3.10](../evaluation/deeptutor-mobile-parity-plan-v0.3.md)。

## 6. LF02：精通目标、精通会话与复习

### 6.1 业务闭环及核心功能

新建精通目标（空路径）→ 编辑大纲模式会话：导师了解学习者并建出大纲 → 学习者同意后切到学习模式 → 导师按下一个目标探查或讲解 → 出题（本轮结束）→ 学习者作答（下一轮，引擎先批改）→ 掌握门禁 → 继续练习或进入下一目标 → 达标后进入复习计划 → 复习模式会话独立回忆 → 答对延长间隔，答错掌握回落并回到学习补救 → 再次达标后继续复习。路径完成不代表复习结束。

| 需求 ID | 功能 | 验收标准 |
| --- | --- | --- |
| LF02-01 | 新建精通目标 | 两步向导（目标 + 图标；资料 + 模型），资料可为空；创建空路径并进入编辑大纲模式会话，自动发送开场消息；路径 ID 稳定 |
| LF02-02 | 大纲协商与修订 | 导师在对话中了解学习者并建出大纲；已有大纲在编辑大纲模式修订，小改直接改，大改先预览后提交，预览过期即拒绝；按名称与类型保持知识点 ID 稳定；先修关系无环；修订影响已有证据时说明影响 |
| LF02-03 | 每轮状态 | 每轮向导师注入状态快照（下一个目标、待答题、到期复习、大纲、学习档案）；下一个目标按 DeepTutor `next_objective`：待答题 → 到期复习 → 按模块顺序的第一个未掌握目标；先修关系只供导师参考，不强制拦截 |
| LF02-04 | 教学与纠错 | 导师按档案选择先探查或先讲解；讲解后记录讲解覆盖；学习者可在会话中追问、延期知识点、报告题目有误；导师不在讲解中泄露待答题答案 |
| LF02-05 | 结构化题卡 | 出题即结束本轮；题型：选择（可用自己的话回答）、简答、开放、题组（2–4 小题）；题卡可跳过；答案与评分依据不出现在题卡上 |
| LF02-06 | 评估与掌握 | 作答作为下一条消息提交，先保存再由引擎批改：选择题与可接受答案精确比对，其他用语义判定；判定不确定时不定分、由导师澄清；定性题取学习者原话评估，模型给出的「通过」不被采信；可复核或申诉判定 |
| LF02-07 | 跳过、延期、报错与自报掌握 | 跳过和延期不是掌握；有误的题可作废或更正；学习者可在证据抽屉中自报掌握，来源显示为「由你确认」，不产生测评证据，可撤销 |
| LF02-08 | 复习 | 复习是复习模式的会话，只对已掌握的知识点出题，到期项优先，也可主动复习未到期项；入口为学习首页、精通之路列表横幅、路径页「下一个」与复习计划 |
| LF02-09 | 复习收尾 | 导师在会话中总结本次复习结果与下次复习时间；提前离开时未处理的到期项保留 |
| LF02-10 | 路径完成及恢复 | 全部知识点掌握（含自报）才算完成；任一知识点回落后路径回到学习中；会话可随时从路径页恢复，跨会话共享进度 |

### 6.2 掌握策略

| 知识类型 | 掌握依据 | 首期规则 |
| --- | --- | --- |
| Memory（记忆） | 检索练习 | 近期加权正确率，阈值 0.9 |
| Procedure（程序） | 独立完成步骤或任务 | 近期加权正确率，阈值 0.9 |
| Concept（概念） | 用自己的话解释、辨析、应用 | 定性评估，取学习者原话 |
| Design（设计） | 方案、作品或综合应用 | 定性评估，取学习者原话 |

定量沿用 DeepTutor `compute_mastery`：最近五次有效独立作答，权重 [0.5, 0.7, 0.85, 0.95, 1.0]，1 次上限 0.5、2 次上限 0.8，部分正确记 0.5。辅助作答（题目带有资料曝光或辅助标记）不计入掌握度，证据质量封顶 0.6。诊断（探查）题按真实作答计分，不注入虚拟记录。自报掌握与系统评估分开记录：在选点、进度和完成判定中按已掌握计算，但不改变测评证据，也不生成复习状态。

### 6.3 复习与回落

复习作答与学习作答走同一评分管线（DeepTutor `_apply_grade` 与定性记录）。从首次评分起维护复习状态，复习计划只显示已掌握的知识点。同一会话内连续答对不提升复习稳定度。复习中独立答错：记录一次失误与错因，掌握度回落到门槛以下，知识点回到学习中，已完成的路径回到学习中；在学习模式重新达标即补救完成，知识点带着失误次数和缩短后的间隔回到复习计划。定量知识点一次失误后需要连续 5 次独立答对才能回到 0.9 以上。

## 7. LF02 状态与执行契约

### 7.1 状态维度

| 状态 | 取值 | 权威对象 |
| --- | --- | --- |
| 路径状态 | 无大纲 / 学习中 / 已完成（由大纲与掌握情况推导） | 路径进度；删除与重置进度需二次确认 |
| 会话模式 | outline / study / review，可在会话中切换 | 会话；工具一律挂载，执行时按模式校验 |
| 知识点状态 | new / learning / mastered；掌握来源 system / learner；延期标记 | 领域规则推导，不由模型设置 |
| 教学进度 | 未讲 / 部分讲解 / 有辅助练习 / 练习未达标 / 独立达标 | 讲解记录与作答证据 |
| 题卡状态 | awaiting_input / answered / graded / skipped；可作废 | 交互记录；未定评分保持可编辑 |
| 回合状态 | queued / running / completed / failed / cancelled / interrupted | Host；同一路径同时只允许一个运行中的导师回合 |

### 7.2 一轮学习的数据时序

1. Host 按路径与会话模式加载最新状态，生成状态快照注入导师；路径与会话 ID 由 Host 绑定，模型不能任意指定。
2. 导师讲解（流式），或写完引导语后调用出题工具；题目经题型、知识点与答案校验后保存为待答题卡，本轮结束。答案与评分依据不出现在公开题卡上。
3. 学习者提交题卡，作为下一条消息发出；Host 先保存原答案（answered）。普通追问、异议不视为作答。
4. 引擎批改：精确比对或语义判定；不确定时保持未定评分。定性题在导师调用评估工具时取学习者原话评估。模型失败时保留答案，不产生通过证据。
5. 写入作答、证据、错因、掌握度与复习状态（M2-A 顺序落库，M2-B 加固为原子事务）。批改结果作为本轮上下文，导师据此回复。
6. 下一轮重新读取状态快照，按 `next_objective` 继续。

### 7.3 复习的独立回忆原则

复习题默认不展示答案、要点或历史错因，题卡上不提供提示按钮。学习者在会话中追问时，导师不直接给出答案；资料页曝光或题目自带的辅助标记会使本次作答记为辅助。答后才展示解析与下次复习时间。复习间隔由调度器根据真实结果与路径的复习策略、记忆保持目标更新。
