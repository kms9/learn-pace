## 5. LF01：自由问答与概念辅导

**目标：** 让学习者能够自由提出问题、理解概念、自主追问，并把有价值的内容转为精通目标。是否进行理解验证由学习者意愿决定，不把自由对话强制转换为测验。

### 5.1 端到端流程

「问答」Tab → 新对话或从会话列表恢复 → 输入问题与可选引用 → 保存用户消息及回合 → 装配模型与授权工具 → 流式展示 → 保存结果 → 继续追问、问 Dito（小老师侧聊）、接受交接卡或转为精通目标。任意时刻退出，重新打开可读取已保存历史及未完成回合。

| 需求 ID | 功能 | 验收标准 |
| --- | --- | --- |
| LF01-01 | 会话创建、继续、历史查询 | 多轮会话恢复准确；会话列表不含小老师侧聊与精通会话；切换模型有记录，不丢失已有消息 |
| LF01-02 | 概念辅导 | 支持直接解释、澄清、苏格拉底提问及分步提示；Markdown 与公式正确渲染；未取得来源时不编造引用 |
| LF01-03 | 授权工具 | 只开放只读的精通之路导航工具（列出路径、列出会话、放置交接卡）；不允许写入任何学习数据；错误、取消及输出具有可观察状态 |
| LF01-04 | 小老师（Dito 侧聊） | 选文 → 「问 Dito」→ 打开侧聊并预填选文 → 追问 → 返回原会话；原消息下显示「小老师 ×N」，可重新打开、删除、解除关联 |
| LF01-05 | 问答自测（考考我） | V0.4（Change 11）纳入：由用户从助手回复「考考我」或输入框快捷入口触发，Host 基于最近对话直接 JSON 生成 1–2 道题，题卡/作答/评分保存在消息 `metadata` 中，复用精确与语义判定；结果只是会话记录，绝不改写 `learning_progress` 或复习计划；判完分提供「继续聊」与「转为学习目标」 |
| LF01-06 | 转入精通之路 | 「转为学习目标」打开新建向导并预选该会话与选文为资料；导师放置的交接卡可进入已有路径的会话；都不会自动标记掌握 |
| LF01-07 | 恢复与重试 | 流式输出中断后保留已提交内容；最后一条回复可重新生成，失败可重试，整轮可删除；重试不重复已完成工具副作用 |

### 5.2 小老师与跨流程切换

**小老师上下文**：以选文所在消息为锚点建立侧聊，保存父会话 ID、锚点消息 ID、选文与选区。每轮请求带入父会话到最新一条的有界记录（每条最多 6,000 字、合计最多 24,000 字，取最近的部分）以及侧聊自身历史。侧聊不写回父会话。

**带回主会话**：选文工具条的「添加到对话框」把选文作为引用条放进主会话输入框，随下一条消息发送。删除整轮时，锚定在被删消息上的侧聊解除关联但保留。

**LF01 → LF02**：
- 「转为学习目标」：打开新建精通目标向导，预选来源会话与选文，由学习者补充目标后创建路径。
- 交接卡：导师判断话题适合继续在某条精通之路学习时，在回复中放置交接卡（路径、进度、可编辑的「开场说」），按钮为「回到这次会话」或「开始学习」。工具不写学习数据，也不自动跳转。

**LF02 → LF01**：在精通会话中，学习者可直接在会话里追问；问答与精通会话互不改变对方的状态。只有通过精通会话的评分管线、精确关联到路径知识点的作答，才影响掌握状态。

### 5.3 数据输入、处理与输出

输入：会话 ID、用户原文、模型配置、引用、教学偏好。处理：回合协调器保存提交请求，Agent 调用外部模型及授权工具，应用层投影文本、工具事件与交接卡。输出：消息、引用、交接卡、工具结果及终态。权威数据为本地会话和提交记录，不依赖模型复述历史。LF01 完成条件是有效响应或明确失败终态与可恢复会话，不要求达到指定掌握度。
