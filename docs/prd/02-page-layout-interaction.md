# 02 · 页面布局与交互

> V0.2 拟议产品设计基线（2026-11-24）。源自 PRD V0.1 和 V0.2 闭环复评；非已实现功能或已通过工程验收。遇到 V0.1 原型与 V0.2 约束冲突，以 V0.2 为拟议修订基线。参见 [复评](../evaluation/learning-loop-review-v0.2.md) 与 [设计索引](../design/README.md)。

## 3. 页面需求与交互（P00–P04）

页面以现有蓝白配色、卡片与统一导航为视觉参考。学习页减少装饰性大头图和重复栏，优先保证正文、公式、答题卡与输入区可见；各页面必须有空态、加载态、错误态及可恢复状态。

| ID | 页面内容 / 布局 | 行为与业务约束 | 原型对应 |
| --- | --- | --- | --- |
| P00 | 学段卡片、自由模式、最近学习 | 选中场景后一次确认；可稍后切换。历史路径跨场景可恢复，不删除旧数据；无依据不显示“推荐” | F01 / D10 |
| P01 | 当前场景、待复习/学习中/已掌握数量、继续学习、今日任务、自由问答 | 优先恢复待答/待评分任务；复习按真实到期队列汇总；任务完成由业务状态产生，不允许勾选即掌握 | F02/F07 / D09 |
| P02 | 顶部模型/历史/新建，中间消息、引用及工具事件，底部输入与停止 | 发送/追问/取消/重试、选中文本、引用或局部辅导；可创建学习目标；默认不强制考试 | D01/D02/D07-C |
| P03 | 路径名称、状态、进度、待复习数量、搜索、筛选、新建 | 草稿/学习中/已完成/归档；复习是任务或会话模式，不替代路径状态；按筛选显示真实记录 | F03/F08 / D09 |
| P04 | 第一步：目标、背景/能力目标；第二步：可选资料与模型 | 允许无资料创建；生成大纲失败仍保留草稿；创建后直达 Outline，不直接标为已掌握 | F04/F09 / D10 |

### 3.1 关键交互细节

- P00 学段选择只是偏好，不限制学习者的真实能力范围；课程来源、学科、年级和教材版本属于后续课程包的结构化属性。未选场景仍能自由问答和创建路径。
- P01 数字来自本地查询：已掌握是知识点数量，学习中是路径数量，待复习是有效到期任务数量，标签明确计量单位。可按当前场景筛选或查看全部。
- P02 提交普通文字只进入问答；互动卡片点击必须产生结构化提交事件，不能把随意追问误当作答题。停止生成不撤销已经提交的工具副作用。
- P03/P04 学习目标与资料可修改，但路径 ID 不变；默认名称由目标派生并允许重命名。删除与归档区别明确，删除须二次确认。
- 资料首期支持文本、引用和必要的本地文件引用；只有具备已授权且可用的解析/模型能力时才读取附件。未解析或网络不可达时显示状态，不能宣称已学习该资料。

## 4. 页面需求与交互（P05–P07）

| ID | 布局与组件 | 行为与业务约束 | 原型对应 |
| --- | --- | --- | --- |
| P05 | 目标、真实进度、大纲、复习任务、学习者画像、最近会话 | 继续学习、编辑大纲、复习、证据详情；同一路径多个会话共享进度；自报掌握和系统评估须区分 | F05/F10 / D09/D11 |
| P06 | 顶部路径/知识点/进度、模式切换、可折叠大纲、消息流、结构化题卡/反馈、追问输入 | 模式独立控制工具权限；题卡持久化后本轮结束；提交答案、提示、跳过、质疑、重试均有明确事件 | F06/F11 视觉参考；D03–D07、D05Q、D11；D06 替代 F12 |
| P07 | Provider、模型、连通性测试、学习偏好、数据导出/恢复、场景切换 | API Key 独立安全存储；首期聚焦 DeepSeek Flash 接入与连通性/工具能力测试；备份前后校验；未配置模型不阻止本地浏览 | D08 |

### 4.1 P06 三种模式

| 模式 | 核心页面状态 | 允许的操作 | 禁止/约束 |
| --- | --- | --- | --- |
| Outline | 大纲草稿、模块列表、预览差异、确认/修改 | 学习者与导师共同确定目标、知识点及依赖 | 禁止正式出题和计入掌握；确认后进入 Study |
| Study | 当前目标、诊断、讲解、练习、反馈与进度 | 学习、提问、结构化答题、评估、纠错、延期目标 | 不随意重建大纲；未达门槛不得宣称系统评估掌握 |
| Review | 到期列表、当前复习点、独立检索、提示、评分、下一次复习 | 复习已经通过掌握门禁/已明示掌握的知识点；可主动复习未到期项 | 不夹带新知识点的正式学习；不默认先泄露答案 |

### 4.2 核心交互状态（V0.2 已有主要原型表达，待实现）

| 状态 | 页面响应与动作 |
| --- | --- |
| 大纲待确认/改动预览 | 展示增删、先修关系和影响的学习证据；确认、取消、继续修改 |
| 待答题 / 待评分 | 展示同一题；提交去重；退出后恢复，禁止重复生成同一题 |
| 答对、部分正确、答错 | 给出依据、薄弱点与下一动作；显示掌握门槛是否达成 |
| 对题目有异议 | 保留原题、讨论、修正或作废；不强制提交答案 |
| 知识点达标 / 路径完成 | 展示掌握结果与证据、后续知识点或复习计划 |
| 复习结算 | 已复习数、需补救项、下一次复习；允许提前结束，未完成任务保留 |
| 模型失败/中断 | 明确失败阶段，保存已有数据；提供继续或重试，不伪造评分 |

### 4.3 页面/交互层仍需补齐的状态

| 优先级 | 所在页 | 缺口 | 通过条件 |
|---|---|---|---|
| P0 | P02/P06 | 实时生成、停止、工具授权、拒绝/超时、模型未配置 | 明确当前阶段；取消不伪造成功；返回原操作 |
| P0 | P06 Outline | 先修冲突/无可学目标、大纲修订删除已评估目标、过期预览 | 解释阻塞原因；提交须检查 Revision；不可误报完成 |
| P0 | P06 Study/Review | 提交中、重复提交、待澄清、评分失败、过期题卡 | 保持同一交互、正确拒绝旧请求、无虚假掌握 |
| P0 | P06 / P05 | 真正的延期知识点、无到期复习、提前退出、主动复习、错误复核结果 | 待办不被清空；延期不是达标；允许非到期主动复习 |
| P0 | P07 | 未配置/测试失败、备份进行中/完成/失败、恢复后凭据重配 | 本地可浏览；失败保留原数据；用户明确同意外发上下文 |
| P0 | 全局 | 空态、草稿、载入/失败、输入键盘/长文本/公式、小屏返回 | 导航不丢草稿、滚动锚点、题卡与会话状态；触控验证 |
| P1 | P05/P07 | 画像及策略编辑细节、全局检索、丰富学习统计 | 明确显式偏好与推断观察，避免标签化 |
