## 3. 页面需求与交互

视觉采用 DeepTutor 主题：浅色底 `#fdfcf9`、主色 `#b0501e`，深色底 `#1a1918`、主色 `#d4734b`；卡片圆角 16–20，中文字体回退到系统字体。各页面必须有空态、加载态、错误态及可恢复状态。模型输出、题干与反馈统一渲染 Markdown 与 LaTeX 公式。

### 3.1 关键交互细节

- **P02 选文**：长按消息打开选文确认层（选区按消息原文计算），动作为「添加到对话框」与「问 Dito」（侧聊在消息标记中称「小老师」，与 DeepTutor 一致）。前者把选文作为引用条放进主会话输入框；后者打开小老师侧聊并预填选文，不自动发送。消息下显示「小老师 ×N」，可打开、删除或解除关联。
- **P02 交接卡**：导师可在回复中放置交接卡，显示路径、进度和可编辑的「开场说」，按钮为「回到这次会话」或「开始学习」；用户点击才跳转。
- **P05 证据抽屉**：显示掌握状态、门槛、历史作答、独立性、评分依据与错因。未经测评达标的知识点提供「我已经掌握，直接放行」（可填写原因，最多 500 字），确认后标注「由你确认」与「已由你标记为掌握；测评证据保持不变。」，可「回到正常测评」撤销。
- **P05 复习计划**：列出到期（「现在可复习」）与即将到期项、遗忘风险和原因；提供复习策略选择与记忆保持目标（70%–99%）；每项可直接开始复习。
- **删除与重置**：删除主题与重置进度都需二次确认。

## 4. P06 精通会话

### 4.1 三种会话模式

一条路径可以有多个会话，每个会话有当前模式。用户可在顶部切换，导师也可在对话中切换（学习者同意时）。切换在生成中不可用。

| 模式 | 中文名 | 导师做什么 | 约束 |
| --- | --- | --- | --- |
| outline | 编辑大纲 | 了解学习者（背景、目标程度、时间、偏好讲解或先测），新建或修订大纲，小改直接改，大改先预览后提交 | 不出正式题、不计入掌握；大纲有内容后会话顶部显示「大纲已就绪——共 N 个知识点」与「开始学习」 |
| study | 学习 | 按下一个目标讲解、出题、批改、记录讲解覆盖；可延期知识点或报告题目有误 | 大纲为空时不可进入；不在学习模式里重建大纲 |
| review | 复习 | 只针对已掌握的知识点出题复习，到期项优先 | 不引入新知识点的正式学习 |

### 4.2 会话内交互

| 状态 | 页面响应与动作 |
| --- | --- |
| 空会话 | 显示「下一个」与当前目标，以及三个起手提示；点提示即发送 |
| 导师讲解 | 流式显示，可停止；中断后保留已收到内容并可重试 |
| 待答题卡 | 选择题（可「用我自己的话回答」）、简答/开放题、题组（2–4 小题一起提交）；「跳过」；题卡提交即作为下一条消息发出 |
| 已批改 | 题卡显示「正确 / 还差一点 / 部分正确 / 未评分，掌握状态不变」与解析；可「复核或申诉本次判定」；导师随后回复 |
| 未定评分 | 语义判定不确定时题卡保持可编辑，导师追问澄清，不改变掌握度 |
| 知识点达标 | 播放升级庆祝动画（遵循系统「减少动态效果」设置） |
| 复习结束 | 导师在会话中总结本次复习结果与下次复习时间；未处理的到期项保留 |
| 模型失败 / 中断 | 明确失败阶段，保存已有数据；提供继续或重试，不伪造评分 |

### 4.3 待补齐的状态

| 优先级 | 所在页 | 缺口 | 通过条件 |
| --- | --- | --- | --- |
| P0 | P02/P06 | 生成中、停止、工具调用失败、模型未配置 | 明确当前状态；取消不伪造成功；可回到原操作 |
| P0 | P06 编辑大纲 | 大纲预览过期、修订删除已有证据的知识点 | 提示原因并重新预览；保留证据 |
| P0 | P06 学习/复习 | 提交中、重复提交、未定评分、评分失败、过期题卡 | 保持同一题卡、拒绝旧提交、无虚假掌握 |
| P0 | 全局 | 空态、载入/失败、键盘、长文本、公式、小屏返回 | 导航不丢草稿、题卡与会话状态；触控验证 |
| P1 | P05 | 看板视图、手工编辑模块、自定义复习间隔 | 参照 DeepTutor `LearningBoard`、`RouteDraftEditor`、`ReviewTrail` 自定义编辑器 |
