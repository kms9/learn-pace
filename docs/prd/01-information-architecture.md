# 01 · 信息架构

> V0.3 拟议基线（2026-11-25）：以复刻 DeepTutor 手机版为目标，参照 DeepTutor `1284116` 的聊天与精通之路信息架构。替代 V0.2 的 P00 场景入口与「首页/问答/路径/我的」Tab 定义。参见[复刻方案](../evaluation/deeptutor-mobile-parity-plan-v0.3.md)。

## 2. 信息架构与页面导航

### 2.1 学习流程

DeepTutor 的聊天与精通之路是两个独立入口，Learn Pace 对应 LF01 与 LF02：

| 流程 | 内容 | 驱动方式 |
| --- | --- | --- |
| LF01 问答 | 多轮聊天、小老师侧聊、交接到精通之路 | 用户提问驱动 |
| LF02 精通之路 | 精通目标 → 精通会话（编辑大纲 / 学习 / 复习三种模式） | 导师在会话中调用工具推进，引擎判定掌握 |

P0 不设学习场景（学段）选择。学段、学科、教材版本属于 P1 课程包的结构化属性。

### 2.2 页面清单与入口

**导航：4 个一级 Tab——学习、问答、精通之路、我的，默认打开「问答」**（对应 DeepTutor 工作区默认进入聊天）。原 P00 场景选择页移除，页面编号保留以便追踪。

| ID / 页面 | DeepTutor 对应 | 进入方式 | 主要去向 | 优先级 |
| --- | --- | --- | --- | --- |
| P01 学习首页 | 学习首页 `LearningDashboard` | 「学习」Tab | P05、P06（到期复习、待答会话） | P0 |
| P02 问答 | 聊天 `ChatWorkspace` | 「问答」Tab（默认）| 小老师、P04、交接卡进入 P06 | P0 |
| P03 精通之路列表 | `TopicAtlas` | 「精通之路」Tab | P04、P05、P06（到期复习） | P0 |
| P04 新建精通目标 | `CreateTopicWizard` | P03「新建精通目标」、P02「转为学习目标」 | P06（编辑大纲模式） | P0 |
| P05 路径页 | 精通之路详情 | P03、P01、P06 返回 | P06 新会话或恢复会话、证据抽屉 | P0 |
| P06 精通会话 | `MasteryStudy` | P04、P05、P01、P02 交接卡 | 同会话内切换模式；返回 P05 | P0 |
| P07 我的 / 设置 | 设置 | 「我的」Tab | 模型配置、数据管理 | P0 |

子页面与弹层（不新增一级入口）：P02 的会话列表、小老师侧聊；P06 的会话内大纲、题卡；P05 的知识点证据抽屉、复习计划。

**导航约束：** 一级 Tab 切换不重建会话。P04 与 P06 为沉浸式页面，隐藏 Tab 栏；返回时保留输入草稿、待答题卡、滚动位置与会话模式。小屏上网页的侧栏与右侧面板改为底部弹层或独立子页面，并保留返回关系。未配置模型时引导到 P07，返回原操作；本地历史浏览不受影响。
