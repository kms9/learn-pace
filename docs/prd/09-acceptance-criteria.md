## 2. 最终学习闭环复评

| 闭环 | 当前原型覆盖 | 尚未验证 |
|---|---|---|
| LF01 会话 | D01、D02、D07-C：新建、解释、追问、历史、局部辅导、可选理解反馈、恢复 | 流式停止、授权工具、引用权限、重试副作用与真实模型接口 |
| LF01↔LF02 | D02-C、D10、D03、D11-C：转目标及关联局部辅导 | 来源版本、路径/知识点映射、提示暴露、跨流程证据准入 |
| LF02 规划教学 | D03–D05Q：目标、大纲、诊断/教学、定性及定量评估、补救、进阶 | DAG 校验、各知识类型评分合同、修订冲突、目标延期/阻塞 |
| LF02 长期保持 | D06、D07-D、D09：到期、独立检索、评估、复习计划、补救及完成后继续复习 | 真实调度算法、到期/未到期、自报掌握、错题回退、无任务状态、时间变化 |
| 数据恢复 | D07、D08、D09、D11-A：原题/作答恢复、状态一致、证据、备份 | SQLite 事务、幂等、崩溃注入、版本冲突、跨数据库恢复、备份完整性 |

**判定：主路径与关键分支已有原型表达，达到可用于技术 PoC 和需求评审的程度；尚不能判定工程闭环、实际学习效果或全部边界状态通过。** 不需新增独立一级页面；缺口主要是状态、可点击原型、业务契约及可执行验收。

### 12.2 P0 最小端到端验收集

| 用例 | 给定 / 操作 | 必须观察到的结果 |
| --- | --- | --- |
| AC-01 LF01 | 配置外部模型；新建问答，追问并退出重启 | 原消息、模型及会话恢复；无额外服务依赖 |
| AC-02 Little Tutor | 选择消息片段并追问；关闭再打开 | 来源与子会话正确，主会话保持不变 |
| AC-03 Handoff | 从 LF01 创建目标；修改并确认大纲 | 来源保留、Path ID 稳定、Study 才开放 |
| AC-04 Mastery Gate | 独立答对三次，分别观察门槛；再测试错答/定性评估 | 分数按政策更新；无证据不达标；不强制所有类型同一流程 |
| AC-05 修复与恢复 | 题卡/作答/评分三个时点杀进程；重复提交/作废题目 | 不重复计分、正确重算、恢复原题或评分 |
| AC-06 Review | 推进测试时钟使任务到期；正确、错误、使用提示各测一次 | 独立性标记正确；任务及下次日期更新；补救分支可进入 |
| AC-07 一致性 | 检查首页、列表、详情、工作台；修改大纲；导出/恢复 | 相同 Revision 下数据一致，证据关联不丢失，备份可恢复 |
| AC-08 原生端 | Android ARM64 真机安装，无 Python 后端，完整执行 AC-01–07 | 可独立执行和重启恢复；iOS 按目标平台再验收 |



## 发布门禁
原型主路径和关键分支已覆盖，不代表功能已实现。AC-01–07 与 AC-08 必须真实通过；故障注入、时间控制、证据有效性、评分复核、Revision 冲突及跨数据库恢复必须验收。P0 不扩大至独立课程市场、内建 RAG、游戏或本地模型推理。
