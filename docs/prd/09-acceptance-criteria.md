# 09 · 闭环验收标准

> V0.3 拟议基线（2026-11-25）：验收场景按[DeepTutor 手机版复刻方案](../evaluation/deeptutor-mobile-parity-plan-v0.3.md)修订，交互以 DeepTutor `1284116` 为参照。本文仅保留唯一权威的验收标准与发布门禁。

## 12. 验收标准与发布门禁

### 12.1 P0 最小端到端验收集

> 首期模型验收以 **DeepSeek Flash** 为准；按阶段推进：技术验证 S7 先确认导师多工具循环可行，M2-A 验收 AC-01–04、AC-06 的主流程闭环，M2-B 补齐事务/CAS/幂等/崩溃恢复后验收 AC-05、AC-07，M3 在真机完成 AC-08 全量发布验收。

| 用例 | 给定 / 操作 | 必须观察到的结果 |
| --- | --- | --- |
| AC-01 问答 | 配置外部模型（首期 DeepSeek Flash）；首次打开应用进入「问答」；新对话、追问、停止、重新生成，退出重启 | 默认进入「问答」；原消息、模型及会话恢复；公式正确渲染；无额外服务依赖 |
| AC-02 小老师 | 选择消息片段并「问 Dito」追问；关闭再从「小老师 ×N」打开；把片段「添加到对话框」 | 侧聊能引用父会话内容，主会话保持不变；侧聊可恢复；引用条随下一条消息发出 |
| AC-03 新建与大纲 | 从问答「转为学习目标」，或在精通之路新建目标；在编辑大纲会话中与导师协商、要求修改一次、同意后切到学习模式；重启 | 资料保留、路径 ID 稳定；会话自动发送开场消息；大纲由导师建出并在修订后保持知识点 ID；出现「大纲已就绪」；切换后可学习；重启后大纲与会话恢复 |
| AC-04 掌握门禁 | 在学习模式中独立答对三次选择题，分别观察门槛；再测试错答、简答或题组、概念题定性评估、跳过与复核；在证据抽屉自报掌握后撤销 | 分数按政策更新；无证据不达标；未定评分不改变掌握；定性取学习者原话；自报掌握显示「由你确认」且不产生测评证据，撤销后恢复原状态；达标时出现升级庆祝 |
| AC-05 修复与恢复 | 题卡/作答/评分三个时点杀进程；重复提交/作废题目（M2-B 加固后全量通过） | 不重复计分、正确重算、恢复原题或评分 |
| AC-06 复习 | 推进测试时钟使已掌握知识点到期；从学习首页进入复习会话；正确、错误、辅助作答各一次；提前离开再进入 | 只复习已掌握知识点；答对延长间隔；答错后掌握回落、路径回到学习中、学习模式可补救；导师在会话中总结下次复习时间；未处理的到期项保留 |
| AC-07 一致性 | 检查学习首页、精通之路列表、路径页、精通会话；修订大纲；导出/恢复（M2-B 加固后全量通过） | 同一状态下进度与到期数一致，证据关联不丢失，备份可恢复 |
| AC-08 原生端 | Android ARM64 真机安装，无 Python 后端，完整执行 AC-01–07 | 可独立执行和重启恢复；更多模型扩展与 iOS 按后续计划验收 |

### 12.2 发布门禁

M3 发布前，AC-01–07 与 AC-08 必须真实通过并记录 ARM64 Release APK 体积与冷启动基线；M2-B 加固阶段的原子事务、故障注入、时间控制、证据有效性、评分复核、大纲版本冲突及跨数据库恢复必须验收。P0 不扩大至多模型兼容矩阵、DeepTutor 的书籍/阅读/题库/Partners 等其他学习形态、内建 RAG、游戏或本地模型推理。

### 12.3 V0.4 增量验收集（M3 发布基线之后）

| 用例 | 给定 / 操作 | 必须观察到的结果 |
| --- | --- | --- |
| AC-09 复习提醒 | 在「我的」开启复习提醒并设时段；产生到期项后划掉后台任务（非 `force-stop`）及开启自启动后重启手机；点击通知（单路径/多路径各一次）与拒绝权限降级 | 后台与重启后本地通知正常触发；通知、学习首页「该做的事」与路径页到期数一致；单路径恢复或打开复习会话、多路径进首页「该做的事」；重复点击不新开多个会话；拒权正常降级无报错 |
| AC-10 问答自测 | 在问答页通过回复「考考我」及输入框快捷入口生成 1–2 题；分别完成作答与未作答强杀重启；重放同 `submission_id`；点「转为学习目标」 | 题目格式合法、正文零答案泄露；强杀重启后未答题卡仍在、重复提交不重复计分；自测前后 `learning_progress` 与复习计划零变化；「转为学习目标」正确预选资料 |
| AC-11 错题与知识卡 | 精通答错与自测答错后打开错题回看，点「去练这个知识点」；长按消息「收藏为知识卡」、题卡判分后「收藏解析」；搜索知识卡并在新建向导中作为 `text_note` 选用；导出 v6 备份、清空、恢复，并恢复一份 v5 旧备份 | 精通错题数与路径页有效非正确证据严格一致（重置进度后无幽灵错题），自测错题标注「未计入掌握」；知识卡支持软删、搜索与新建引用；v6 往返与 v5 兼容恢复完整，迁移故障可整体回滚 |
| AC-12 语音输入与整合基线 | 在问答与简答题输入框实测系统中文输入法语音输入；真机走完「提醒 → 复习 → 答错 → 错题 → 知识卡 → 新建路径」全链路，对比阶段 0 Release APK 体积与冷启动时间 | 中文语音输入法正常上屏无焦点异常；全链路与备份往返闭环通过；记录相对 M3 基线的安装包体积与冷启动变化 |
